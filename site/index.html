Living repository

Contribute a measure

STAC grows through the community. You can submit a new scale or task, a new language version, or a correction. No Git knowledge is needed: the submission form accepts file attachments, and a moderator turns it into a reviewed pull request.

From submission to release

  1. Open the submission form

    Fill in acronym, title, section, languages, references and the access tier. Attach the files (zip survey exports such as .qsf, .que or .lss, GitHub does not accept them as single attachments).

  2. Automatic pre-check

    A bot drafts the folder and stac.yml from your form and posts a validation report: missing citations, files not described in the README, unsupported formats, junk inside archives.

  3. Curator review

    A section curator checks the inclusion criteria and opens a pull request. Code owners of the section must approve it.

  4. Merge and publish

    After merging, the catalog, previews and README tables rebuild automatically and the measure appears here within minutes.

  5. Versioned release with DOI

    Each release is archived on Zenodo with a DOI and per-instrument download bundles, so every version stays citable.

The OSF archive (osf.io/4s9p6) stays online as the frozen, citable state of October 2026. Everything added later appears only here, marked New. Follow additions with the Atom feed or by watching releases on GitHub.

Submit a measure

Inclusion criteria

From Kenett, Silvia & Benedek (2026)

  1. The measure captures constructs relevant to creativity, aesthetics or the arts, or individual differences in personality or cognitive ability of interest in this context.
  2. It was published in a peer-reviewed journal with basic evidence of psychometric quality.
  3. You have permission to share the materials openly, typically as author of the measure or of a translation. Measures that require permission or a license to use are not included.
  4. You provide the materials plus a readme with an overview of the files, administration and scoring, per-language references and confirmation that the measure is free for academic, non-commercial use.

File naming

Use ACRONYM_Language[_Platform][_Variant].ext, for example SSCS_German_Qualtrics.qsf or HEXACO-PI-R_English_60.docx. The catalog reads language and platform from these tokens.

About this archive

About STAC

STAC was created in 2013 by Paul Silvia on the Open Science Framework as "Creativity and Arts Tasks and Scales: Free for Public Use". Mathias Benedek joined as moderator in 2018 and Yoed Kenett in 2024. The archive is supported by APA Division 10 and the Society for the Neuroscience of Creativity.

Who can do what

Everything committed to the public repository is readable and downloadable by anyone. Materials with restricted access never enter the repository; they are released through access requests.

Privacy in short

No cookies. Views and downloads are counted with a salted hash of IP address and browser that changes every day; IP addresses and user agents are never stored. If you opt in, a random ID stays in your browser so you can see your own download history under a pseudonym such as "curious-otter-3f9a". Raw events are deleted after 90 days; only daily totals remain. Messages and e-mail addresses go to a private inbox that only moderators can read.
