# PAI – Product Aesthetics Inventory

## Overview

This folder contains files related to PAI – Product Aesthetics Inventory. This tool was originally developed by Thielsch et al. (2022). It has a standard form and a short form (marked by the -S file name).

## Files

* **PAI-S\_English.docx**
* **PAI-S\_German.docx**
* **PAI\_English.docx**
* **PAI\_German.docx**

## Administration and Scoring

See the references below for information on scoring the PAI.
