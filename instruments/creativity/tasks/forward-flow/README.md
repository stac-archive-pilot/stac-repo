## Overview 
This folder contains files related to Forward Flow. Fward Floorw is a Chained Free Association Task, where participants generate chained associates (I.e., a word that comes to mind as related to a previous word) from a specific cue word. Computational semantic spaces are used to compute the semantic distance between each pair of words. The average over these scores is the measure Forward Flow, which empirically quantifies he breadth of associative search of a person. This measure has been shown to be significantly related to divergent thinking.

## Files
- FF.qsf: a Qualtrics implementation of the task.
- Gray et al., 2019.pdf: Original paper describing the method and its validation.
- Beaty, Zeitlen, Baker, and Kenett, 2021: validation study that also includes the R code for analysis
