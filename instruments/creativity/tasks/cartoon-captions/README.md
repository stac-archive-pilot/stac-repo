# Cartoon Captions

## Overview

This folder contains files related to Cartoon Captions. Asking people to write funny captions for single-panel cartoons is one of the oldest and most widely-used tasks for measuring creative humor production. These files (and the MediaLab file) are from Nusbaum et al. (2017), cited below, which provides instructions and guidance for administration and scoring.
