# Funny Definitions Task

## Overview

This folder contains files related to Funny Definitions Task. This was developed by Nusbaum et al. (2017) to study individual differences in creative humor production.

## Files

* **Funny Definitions Task\_English.docx**
* **Funny Definitions Task\_English.pdf**
* **Funny Definitions Task\_English\_MediaLab.que**
