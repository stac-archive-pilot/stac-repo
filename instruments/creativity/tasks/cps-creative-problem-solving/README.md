# CPS - Creative Problem Solving

## Overview 
This folder contains files related to CPS - Creative Problem Solving. CPS is an open ended task, where participants are presented with open-ended, ambiguous, real-life problems. They must first identify and describe the dilemma (problem construction) and then propose a solution to it (problem solving). 

## Files
- CPS.qsf - a qualtrics version of the CPS task
- Luchini et al., 2025.pdf - a paper describing an automatic tool that scores the CPS task.
- Arreola & Reiter-Palmon, 2016.pdf - a review of the task

## Administration and Scoring
Administration instructions can be found in the attached papers. Automatic scoring is provided by Luchini et al., 2025 and its implementation can be found at: https://osf.io/hsxza/overview
