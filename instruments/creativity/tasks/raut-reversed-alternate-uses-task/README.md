# rAUT-Reversed Alternate Uses Task 

## Overview

This folder contains files related to the Reversed Alternate Uses Task. This was developed by Scherbakova et al. (2025) to measure domain general creative thinking. Researchers should consult the article for additional details on administration and scoring.
