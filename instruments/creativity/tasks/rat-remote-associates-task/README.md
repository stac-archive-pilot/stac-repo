# RAT – Remote Associates Task

## Overview 
This folder contains files related to RAT – Remote Associates Task. 

## Files
- **RAT_English_Psychopy_Lloyd-Cox.zip**
- **RAT_English_Qualtrics_Lloyd-Cox.zip**
- **CAT40_French_Matlab_Volle.zip**

## Administration and Scoring
For the French RAT (CAT): 
A detailed readme_CAT40.txt is provided in zip file for additional information.
A manual cleaning is needed to clear the answers from plurals, conjugated verbs, non-words, and typos. This allows automatic comparison of participants' responses with the list of accepted responses for each trial.
The file Lists/TAC/WordLists/TAC40_list_strictCorrect_memowave.csv contains the list of the responses considered correct (columns E to P). Please check it before using it.
