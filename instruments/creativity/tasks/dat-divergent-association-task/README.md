# DAT - Divergent Association Task

## Overview 
This folder contains files related to DAT - Divergent Association Task. In the DAT, participants are required to come up with ten words that are unrelated to each other. This short task has been found to correlate with DT.

## Files
- Haase et al., 2025.pdf - a LLM-based to automatically score multilingual DAT performance.
- Olson et al., 2021.pdf - original paper presenting the task
- DAT.qsf - a qualtrics implementation of the task

## Administration and Scoring
Administration can be achieved via the qualtrics file or the online tool: https://www.datcreativity.com/about
Scoring can be done based on instruction in Olson et al., 2021 or automatically based on the tool described by Haase et al., 2025
