# SGT - Story Generation Task

## Overview 
This folder contains files related to SGT - Story Generation Task. In the SGT, participants write a 5 sentence short story to a prompt of three cue words. The richness, or originality of the language used in the short story can be automatically evaluated via the DSI tool. 

## Files
- Howard-Jones et al., 2005.pdf - the paper presenting the task
- Johnson et al., 2023.pdf - the paper presenting the DSI tool that can score the SGT
- Story_Generation_Task.qsf - a qualtrics implementation of the SGT

## Administration and Scoring
The SGT can be automatically scored by the DSI tool (Johnson et al., 2023) which can be achieved via: https://cap.ist.psu.edu/dsi
