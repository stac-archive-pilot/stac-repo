# Quirky Questions Humor Task

## Overview

This folder contains files related to the Quirky Questions Task. This task was developed by Silvia and Bui (2026) as a fully text-based task for measuring creative humor production.

## Files

* **Quirky\_Questions\_Task\_Scoring\_Instructions\_English.pdf**
* **Quirky\_Questions\_Task\_English\_Word.qsf**
* **Quirky\_Questions\_Task\_English\_Qualtrics.qsf**

## Administration and Scoring

See the cited article below and the "Scoring Instructions" file for additional directions on administration and scoring. Additional research materials for this task are available at its [OSF archive](https://osf.io/p2asv/overview).
