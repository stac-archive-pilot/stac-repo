# Joke Stems Task

## Overview

This folder contains files related to Joke Stems Task. This task was developed by Nusbaum et al. (2017), cited below, and has been widely used in recent studies of creative humor production.

## Files

* **Joke Stems Task\_English.docx**
* **Joke Stems Task\_English.pdf**
* **Joke Stems Task\_English\_MediaLab.que**
* **Joke Stems Task\_English\_Qualtrics.qsf**

See the cited article below for additional directions on administration and scoring.
