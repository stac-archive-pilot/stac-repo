# RIBS – Runco Ideational Behavior Scale

## Overview

This folder contains files related to RIBS – Runco Ideational Behavior Scale. The RIBS is a widely-used self-report measure of ideational behavior. Originally developed in English, it has since been translated into many, many languages. This archive contains English, French, and German versions.

## Citation

### Original English Version

Runco, M. A., Plucker, J. A., \& Lim, W. (2001). Development and psychometric integrity of a measure of ideational behavior. *Creativity Research Journal, 13*(3-4), 393-400.

### French Version

### German Version

Weiss, S., Goecke, B., \& Wilhelm, O. (2026). Leveraging Cattell's data types to understand creativity from different research traditions. Learning and Individual Differences, 129, 102928.
