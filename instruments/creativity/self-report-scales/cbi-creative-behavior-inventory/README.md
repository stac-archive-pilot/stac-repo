# CBI – Creative Behavior Inventory

## Overview

This folder contains files related to CBI – Creative Behavior Inventory. The CBI has had many versions of the years. It was created by Hocevar (1979); the original scale is included below for historical interest. The most widely used version is a short form developed by Dollinger (2003). A German translation is available.

## Files

* **CBI\_English.pdf**
* **CBI\_English\_MediaLab.que**
* **CBI\_English\_Original\_90\_Item\_Form\_Hocevar\_1979.pdf**
* **CBI\_German.pdf**

## Administration and Scoring

Details about the history of the CBI, its changes over the years, and its scoring and administration can be found here:

Rodriguez, R. M., Silvia, P. J., Kaufman, J. C., Reiter-Palmon, R., \& Puryear, J. S. (2023). Taking inventory of the Creative Behavior Inventory: An item response theory analysis of the CBI. *Creativity Research Journal, 35*(2), 143-153.
