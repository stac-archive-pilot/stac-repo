# CSES – Creative Self-Efficacy Scale

## Overview

This folder contains files related to the Creative Self-Efficacy Scale developed by Lamb et al. (2025). Researchers interested in measuring creative self-efficacy might also consider the SSCS (Short Scale of Creative Self) elsewhere in the STAC archive.

## Files

* **CSES\_Creative\_Self\_Efficacy\_Scale\_English.pdf**

## Administration and Scoring

The attached file, provided by Kristen Lamb, contains detailed instructions for administration and scoring.

If you use this measure in your published work, please cite the reference(s) below:
