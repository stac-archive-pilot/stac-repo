# SoCSC - Sources of Creative Self-concept

## Overview 
This folder contains files related to the Sources of Creative Self-concept scale.
It assesses experiences with Bandura's four sources of information of self-efficacy.
The scale comes in two flavors:
- The main SoCSC includes six items per source and asks if specific experiences apply.
- The SoCSC-V includes two items per sources and asks how often people have made positive and negative experiences with each source.

## Files
- **SoCSC_English.docx:** English version of the SoCSC
- **SoCSC_German.docx:** German version of the SoCSC
- **SoCSC_English:** English version of the SoCSC-V 
- **SoCSC_German:** German version of the SoCSC-V
