# Creativity Myths & Facts Scale

## Overview 
This folder contains files related to the Creativity Myths & Facts scale

## Files
- **CMF_German.docx:** German version
- **CMF_English.docx:** English version
- **CMF_English.pdf:** Japanese version

## Administration and Scoring
###Administration
•	All 30 items are presented in randomized order
•	Instruction: Please indicate for each statement if you think it is right or wrong, or otherwise choose "Don't know",
•	Response format: Correct, Incorrect, Don’t know
###Scoring
•	Endorsement creativity myths = (#myths = agreed) + 0.5 * #(myths = don’t know)
•	Endorsement creativity facts = (#facts = agreed) + 0.5 * #(facts = don’t know)
•	Creativity knowledge = Endorsement creativity facts - Endorsement creativity myths
