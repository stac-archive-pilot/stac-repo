# CPS – Creative Personality Scale

This folder contains files related to CPS – Creative Personality Scale.



Gough's Creative Personality Scale was based on the Adjective Check List. It was one of the early measurement tools in the study of personality and creativity and was widely used. In modern work, most creativity researchers would agree that this scale is historically important but seriously outdated as a tool for understanding creativity and personality.
