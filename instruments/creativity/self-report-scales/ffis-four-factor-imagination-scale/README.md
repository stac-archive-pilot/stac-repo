# FFIS – Four-Factor Imagination Scale

## Overview

This folder contains files related to FFIS – Four-Factor Imagination Scale, a self-report scale developed by Zabelina and Condon (2020). Additional self-report measures of imagination are available in STAC.

## Files

* **FFIS\_English.docx**
* **FFIS\_English.pdf**

## Administration and Scoring

See the original article for details about administration and scoring.
