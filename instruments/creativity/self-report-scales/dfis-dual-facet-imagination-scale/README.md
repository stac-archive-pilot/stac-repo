# DFIS – Dual Facet Imagination Scale

## Overview

This folder contains files related to DFIS – Dual Facet Imagination Scale. Developed by Sassenberg et al. (2023), this scale proposes two facets of imagination that link to the BFAS Openness and Intellect aspects. Additional self-report imagination scales are available in the STAC archive.

## Files

* **DFIS\_English.docx**
* **DFIS\_English.pdf**
* **DFIS\_German.docx**
* **DFIS\_Turkish.docx**

## Administration and Scoring

See the articles below for details on administration and scoring. The QSF file is recommended for Qualtrics users.
