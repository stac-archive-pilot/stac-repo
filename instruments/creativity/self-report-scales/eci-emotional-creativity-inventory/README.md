# ECI – Emotional Creativity Inventory

## Overview

This folder contains files related to ECI – Emotional Creativity Inventory. The scale is available in its original English form (developed by Averill, 1999) and a German translation (developed by Weiss et al., 2025).

## Files

* **ECI\_English.docx**
* **ECI\_English.pdf**
* **ECI\_German.docx**
* **ECI\_German.pdf**
