# Getting help with STAC

| You need | Where to go |
|---|---|
| Find a measure, its files and how to cite it | The [STAC website](https://stac-archive.github.io/stac/) and the `README.md` in each instrument folder |
| Help with choosing, administering or scoring a measure | [Discussions: Q&A](https://github.com/stac-archive/stac/discussions/categories/q-a) |
| Report a wrong item, scoring key, citation or broken file | [Report an error](https://github.com/stac-archive/stac/issues/new?template=03-error-report.yml) |
| Know whether you may use a measure for a specific purpose | Check the licence statement on the instrument page, then ask via [Licensing question](https://github.com/stac-archive/stac/issues/new?template=06-license-question.yml) |
| Contribute a measure or translation | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Request restricted materials, or contact the moderators confidentially | [Private message form](https://stac-archive.github.io/stac/#/board?tab=private) |
| Report a security problem with the website or backend | [SECURITY.md](SECURITY.md) |
| The original OSF archive | [https://osf.io/4s9p6](https://osf.io/4s9p6) |

## What to expect

STAC is maintained by volunteers. We aim to respond to new issues within about a week (see [GOVERNANCE.md](GOVERNANCE.md#review-times)). Questions in Discussions are often answered faster by other researchers.

Questions about the **content** of a measure (theory, norms, unpublished data) are best directed to its authors; the README of each measure lists the original publication.

Curators can explain what an access tier means, but cannot give legal advice. For commercial or clinical use, the authors or rights holders decide.

## Citing STAC

When you use a measure, cite the reference given in its README for the language version you used. To refer to the archive itself, cite:

Kenett, Y. N., Silvia, P. J., & Benedek, M. (2026). Scales and Tasks for Art and Creativity Assessment (STAC). *Psychological Test Adaptation and Development, 7*, 239-244. [https://doi.org/10.1027/2698-1866/a000140](https://doi.org/10.1027/2698-1866/a000140)
